# Arquivo histórico do workspace

Esta pasta preserva artefatos que não representam o build atual `0.6.0a1`,
mas que podem ser úteis como evidência acadêmica ou para rastrear versões
anteriores.

- `packages/v0.5.0a1/`: wheel histórico `trq-bec 0.5.0a1`.
- `backups/api-docs/`: backups automáticos anteriores à documentação atual.

Esses arquivos não entram no pacote principal de código-fonte e não devem ser
instalados sobre o ambiente atual. O build oficial atual é gerado a partir de
`backend_trq_bec/pyproject.toml` e deve produzir a versão `0.6.0a1`.
